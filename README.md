# SaaS Subscription & Expense Analytics Dashboard

An end-to-end full-stack analytics platform to track, manage, and optimize SaaS subscriptions.

## Tech Stack
* **Backend:** Java 21, Spring Boot 3.3.0, Spring Data JPA, Spring Security, JWT, H2 Database
* **Frontend:** React, Vite, Tailwind CSS, Lucide Icons, Recharts

## Getting Started

### Backend Setup
```bash
cd backend
./mvnw.cmd clean spring-boot:run
```
* Runs on: http://localhost:8080

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
* Runs on: http://localhost:5173
